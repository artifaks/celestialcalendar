# Celestial Calendar

A React web application for exploring ancient calendar systems and discovering cosmic connections.

## Features

- **Astrology Calculator** — Calculate sun, moon, and rising signs from birth date, time, and location
- **Egyptian Calendar** — Ancient Egyptian timekeeping with lunar phases and sacred festivals
- **Dogon Calendar** — Traditional Dogon dual calendar system with solar and lunar tracking
- **Mayan Calendar** — Tzolkin and Haab calendar systems with Long Count date calculations

## Tech Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- React Router DOM
- Lucide React icons

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Deployment

This app is deployed on [Netlify](https://celestialcalendar.netlify.app).
